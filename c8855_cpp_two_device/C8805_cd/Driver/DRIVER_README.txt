C8855-01 device driver package version 3.2.0.0:

This driver package allows users to control the counting unit C8855-01 on Windows operation systems (Windows 8.1 Pro and 10 Pro).
Please refer to C8855-01 instruction manual about how to install the driver.

The following files are installed on PC after the driver installation:
・C8855-01api.dll
・libusb-1.0.dll

C8855-01api.dll is a dynamic link library that allows userspace application to communicate with the counting unit C8855-01. This library was compiled by linking with libusb-1.0.


libusb is a library for USB device access from Linux, macOS, Windows, OpenBSD/NetBSD and Haiku userspace. It is written in C (Haiku backend in C++) and licensed under the GNU Lesser General Public License version 2.1 or, at your option, any later version.

libusb is abstracted internally in such a way that it can hopefully be ported to other operating systems. 

libusb homepage: http://libusb.info/

Developers will wish to consult the API documentation: http://api.libusb.info
