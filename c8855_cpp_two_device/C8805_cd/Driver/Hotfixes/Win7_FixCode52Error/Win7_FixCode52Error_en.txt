Hotfix for Code 52 Error on Windows 7
=====================================

## What is Code 52 Error ?
--------------------------------
If your PC is running on Windows 7, and is not up-to-date with Windows Update, the latest algorithm for digital signature (e.g. SHA-256) may not be supported properly.
In this situation, Windows cannot use the kernel driver and it is shown in Device Manager as Code 52 Error.

## How to avoid Code 52 Error
--------------------------------
The necessary files to fix this error are currently provided by Microsoft through Windows Update. 
The recommended way to avoid this error is to connect PC to the Internet and apply Windows Updates.  
If PC cannot use Windows Update, you can download hotfix files from Microsoft's website.
Applying the hotfix files will fix this issue.
For PC's already connected to the Internet and allowing automatic Window's Update, installation will proceed normally.  Code 52 Error will not occur.

## Run RunOnceFirst_AsAdmin.bat as Administrator
--------------------------------
Hotfixes folder includes necessary files for fixing Code 52 Error.
Please run the following batch file as Administrator.

    Hotfixes\Win7_FixCode52Error\RunOnceFirst_AsAdmin.bat 

Necessary Hotfix files will be installed.
Once Hotfix is applied, restarting PC is required.
Please follow the directions provided by the batch file.

## Disappear Windows Security Dialog
--------------------------------
You may see Windows Security dialog during installation of the driver and/or hardwares.
The dialog will includes following information.

    Name: Hamamatsu Photonics K.K. (Device Type)
    Publisher: Hamamatsu Corporation

Hamamatsu Corporation is a subsidiary company of Hamamatsu Photonics K.K.
After installing above hotfix files, this Windows Security dialog during installation of the driver and/or hardwares will not appear.
